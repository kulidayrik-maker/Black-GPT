BLACK GPT — ПОЛНЫЙ КОМПЛЕКТ

В этом архиве уже есть и сайт, и локальный помощник для вкладки Code.

1) Для публикации сайта: отправь ВСЁ содержимое корня архива в репозиторий GitHub Black-GPT (с заменой старых файлов). Не загружай папку LOCAL-AGENT-STANDALONE как часть Pages root — это дополнительная копия помощника.
2) В корне проекта уже лежат blackgpt_agent.py и start-black-gpt-agent.bat. После клонирования репозитория можно запустить этот .bat.
3) Для запуска отдельной копии помощника без GitHub используй файлы в LOCAL-AGENT-STANDALONE.
4) Установи Python 3.10+ и запусти start-black-gpt-agent.bat. Выбери разрешённую папку проекта, оставь окно открытым и введи одноразовый код во вкладке Code на сайте.

Не добавляй API-ключи в файлы проекта. AI_API_KEY должен оставаться Cloudflare Secret.
