BLACK GPT — ОБНОВЛЁННЫЙ ПОЛНЫЙ КОМПЛЕКТ

В архиве есть сайт Black GPT, новая IDE-вкладка Code, Image Studio для генерации картинок и локальный помощник Windows.

1) Для сайта: скопируй всё содержимое корня архива в корень репозитория Black-GPT, замени старые файлы и отправь Commit + Push через GitHub Desktop. Не загружай LOCAL-AGENT-STANDALONE как Pages root — это отдельная копия локального помощника.
2) Cloudflare Pages: Build Command = exit 0; Build output directory = .; Deploy Command в твоём текущем пайплайне = npx wrangler pages deploy . --project-name ИМЯ_ТВОЕГО_PAGES_ПРОЕКТА. Если проект уже настроен на автоматический Pages deploy из Git, не меняй рабочую команду без необходимости.
3) Сохрани существующие AI_API_KEY, AI_BASE_URL и AI_MODEL — они обслуживают текстовый чат и Code.
4) Для генерации изображений добавь в Cloudflare Pages → Settings → Variables and Secrets отдельный Secret OPENAI_API_KEY. Не используй в нём Groq-ключ. Необязательная обычная переменная IMAGE_MODEL = gpt-image-2.5-flare. Генерация изображений оплачивается отдельно по условиям OpenAI API; доступ к Image API и биллинг должны быть активны. Перед публикацией для всех добавь Cloudflare Rate Limiting Rule для пути /api/image, например не более 2 запросов за 60 секунд с одного IP.
5) Для Code: установи Python 3.10+, запусти start-black-gpt-agent.bat, выбери папку проекта и введи одноразовый код на сайте в Code. Окно помощника должно оставаться открытым.
6) В IDE подключён Monaco Editor с подсветкой синтаксиса, несколькими вкладками, поиском файлов и AI-панелью. Если CDN редактора недоступен, останется базовый встроенный редактор.

Защита: API-ключи не добавляй в код, архив или GitHub. Локальный помощник работает только в выбранной папке, скрывает секреты, делает backup перед записью и не запускает команды. Все изменения ИИ необходимо проверить перед применением.
