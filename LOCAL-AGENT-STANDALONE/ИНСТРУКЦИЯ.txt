BLACK GPT — ЛОКАЛЬНЫЙ ПОМОЩНИК ДЛЯ CODE

1. Установи Python 3.10+ для Windows.
2. Дважды нажми start-black-gpt-agent.bat.
3. В открывшемся диалоге выбери папку проекта, которую разрешаешь редактировать.
4. Не закрывай чёрное окно. Скопируй из него одноразовый код подключения.
5. На сайте https://black-gpt.pages.dev открой вкладку Code, вставь код и нажми Подключить.
6. При первом подключении браузер может запросить доступ к локальному компьютеру/локальной сети — разреши доступ сайту.

Ограничения:
- Помощник читает и записывает только выбранную папку.
- .env, ключи, пароли, приватные ключи, .git, node_modules и бинарные файлы пропускаются.
- При записи создаются резервные копии в .blackgpt-backups.
- Black GPT не запускает команды и программы на ПК. Он только готовит изменения, которые ты проверяешь и отдельно подтверждаешь.
- Остановить помощник: Ctrl+C или закрыть его окно.
