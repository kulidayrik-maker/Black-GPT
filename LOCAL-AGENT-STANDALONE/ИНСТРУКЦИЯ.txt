BLACK GPT — ЛОКАЛЬНЫЙ ПОМОЩНИК ДЛЯ CODE

1. Установи Python 3.10+ для Windows.
2. Дважды нажми start-black-gpt-agent.bat.
3. В диалоге выбери папку проекта, к которой разрешаешь доступ.
4. Оставь окно открытым и скопируй одноразовый код подключения.
5. На сайте Black GPT открой вкладку Code, введи код и нажми «Подключить ПК».
6. Выбирай файлы, добавляй нужные в контекст и отправляй задачу Black GPT Code.
7. Перед применением правок просмотри diff и нажми «Применить» только если изменения правильные.

Безопасность:
- помощник работает только внутри выбранной папки;
- .env, секреты, ключи, пароли, .git, node_modules и бинарные файлы исключены;
- перед сохранением создаются резервные копии в .blackgpt-backups;
- запись происходит только после подтверждения пользователя;
- локальный помощник не запускает команды, скрипты и программы.

Остановить помощник: Ctrl+C или закрыть его окно.
